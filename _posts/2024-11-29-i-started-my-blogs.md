## The early days
I remember when I was in college, we were just introduced about the .np domain. And everyone who studied Computer Science was obsessed with it, the one who launches their portfolio site with .np domain was hero.  We could get it free, the only requirements were to provide administrative documents and that's it. So, I also registered for it because it seemed cool at that time to have an own personal domain.

Today, I am finally starting to use it to write my things and post it here. This domain has come a long way, until yesterday I had used it for a simple portfolio site which was made just to utilize the domain. I hadnt updated it for like 4 long years. I can barely remember it now, it looked bad. I regret that I didnt take any screenshots of the site, I dont have the code anymore either, otherwise, It would be fun to give a look sometime in future how my first portfolio site looked like.

I guess it was 2017, I had just started with HTML, CSS and JS and had a basic knowledge of a website. I downloaded a template, edited it with some difficulty and made an okay looking website. After that, it was again a tedious thing to do for someone like me who barely knew how a website used to be deployed. `.np`  domain allowed only domain, so had to use github pages to host the website, so after some help of some hostel friends, I finally had my own portfolio site live. It was an achievement those days.

After that I had been periodically updating the side but only minor things, it was like my resume. Recently, an interest of writing journals or documenting the things about my life, so I cloned a jekyll theme, modified a bit and it's ready to used for my blogs.

## Moving on
I would say my portfolio will never go in a release mode, it has always been in a beta version all the time. And I believe, it will just keep evolving but never turn into a final one. And it doesnt need to be either. For now it works and is stable. This version of this site will for sure stay around for some years. Because, I dont have energy to update the site, I even dont have `jaangar` to write blogs, can't imagine to update the whole code base. So, I will be around here with this style...
